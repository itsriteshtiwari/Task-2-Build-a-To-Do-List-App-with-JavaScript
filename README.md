# Task-Build-a-To-Do-List-App-with-JavaScript

A clean, responsive, and fully functional To-Do List application built with Vanilla JavaScript. This project focuses on DOM manipulation, state management, and data persistence using the browser's Local Storage, featuring a modern, system-style user interface.


## ✨ Features
*   **CRUD Operations:** Seamlessly add, view, update (mark as done), and delete tasks.
*   **Data Persistence:** Tasks are saved in `localStorage`, ensuring data remains intact even after refreshing or closing the browser.
*   **Dynamic Filtering:** Instantly sort tasks by "All", "Active", "Done", or "High Priority".
*   **Priority Tagging:** Assign and visually track task priority levels (High, Medium, Low).
*   **Real-time Statistics:** A dashboard tracking Total, Done, and Remaining tasks.
*   **System UI Design:** A minimalist, lightweight aesthetic prioritizing user experience.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure and layout.
*   **CSS3:** Custom styling, flexbox layouts, interactive hover states, and conditional rendering classes.
*   **Vanilla JavaScript (ES6+):** Event listeners, array methods (`filter`, `map`, `sort`), and JSON parsing for local storage integration.
